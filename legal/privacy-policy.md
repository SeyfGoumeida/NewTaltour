## 2. Données collectées

Nous collectons les données suivantes lorsque vous utilisez NewTaltour :

### Données de compte
- Nom et prénom
- Adresse email
- Numéro de téléphone
- Adresse postale
- Date de naissance
- Numéro de permis de conduire

### Données de réservation
- Véhicule réservé
- Dates de location
- Lieux de pick-up/retour
- Montant de la réservation
- Historique de paiement

### Données techniques
- Adresse IP
- Type de navigateur
- Pages visitées
- Durée de visite
- Cookies

## 3. Base juridique

Nous traitons vos données sur la base de :
- **Contrat** : Exécution de vos réservations
- **Consentement** : Newsletters et communications marketing
- **Obligations légales** : Droit fiscal et comptabilité
- **Intérêts légitimes** : Prévention de fraude et sécurité

## 4. Durée de conservation

- **Données de compte** : Pendant toute la durée de votre compte
- **Données de réservation** : 3 ans après la fin de la réservation (légalement requis)
- **Données de paiement** : 7 ans (obligation légale)
- **Logs d'accès** : 3 mois maximum

## 5. Vos droits

Conformément au RGPD, vous avez le droit de :
- **Accès** : Demander l'accès à vos données
- **Rectification** : Corriger vos données inexactes
- **Suppression** : Demander l'effacement de vos données
- **Portabilité** : Recevoir vos données dans un format portable
- **Opposition** : Vous opposer au traitement de vos données

## 6. Sécurité

Nous mettons en place les mesures de sécurité suivantes :
- Chiffrement SSL/TLS pour les transmissions
- Hashage des mots de passe (bcrypt)
- Contrôle d'accès basé sur les rôles
- Audit logs pour les accès administrateur
- Tests de sécurité réguliers
